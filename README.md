# service.auth

Secure, auditable authentication and authorization for AI agents and service-to-service workloads.

## Why

Modern agentic systems need more than a bearer token: they need verifiable workload identity, narrowly scoped permissions, short-lived credentials, and an audit trail that explains who acted, what they accessed, and why.

`service.auth` is a lightweight, self-hostable control plane for those primitives.
